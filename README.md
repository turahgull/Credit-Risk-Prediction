# Credit Risk Prediction & Default Analysis

This project is a Machine Learning-based system developed to predict whether a loan applicant is likely to default or not.

## 📊 Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

## 🏆 Best Model
Random Forest achieved the best performance based on:
- Accuracy
- Recall
- F1-Score
- AUC-ROC

## 📁 Dataset
- credit.csv

## ⚙️ Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib / Seaborn

## 📌 Key Features
- Data preprocessing and cleaning
- Model comparison
- Confusion matrix visualization
- ROC Curve and AUC evaluation

## 📈 Conclusion
Random Forest is selected as the final model because it effectively identifies high-risk applicants and improves decision-making in loan approval.

## 💡 Business Impact
- Helps reduce financial risk
- Supports better loan approval decisions
- Improves efficiency of the process
